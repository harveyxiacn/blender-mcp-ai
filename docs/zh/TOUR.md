# Blender MCP 分层演示教程

## 概览

想最快看到这个项目能做什么、每一部分分别负责什么，从这里开始。

`scripts/demo_tour.py` 会通过 MCP socket 搭出一个小型场景，分成**八个图层**，每个图层归入一个独立集合。
你可以随时在 Blender 里把某一层单独显示出来，逐层看清楚。

所有操作都走真实客户端用的那条 socket，所以**只要演示全绿，就说明你的安装端到端是通的**。

## 前置条件

- Blender 4.0+ 正在运行，且 Blender MCP 插件已**启用**（监听 `127.0.0.1:9876`）
- 项目已安装：`uv sync`
- 建议在空场景里跑，`--clean` 参数会帮你清空

## 运行

```bash
uv run python scripts/demo_tour.py --clean
```

预期输出：

```
Connected to Blender 5.2.2 LTS

Scene cleared.

  L1_场景基础        5/5 ops  [OK]
  L2_建模          9/9 ops  [OK]
  ...
  46/46 operations succeeded
```

如果有失败，脚本会逐个打印错误码，并以非零退出码结束。

## Blender 界面速查

你只需要会这几件事：

| 想做什么 | 怎么做 |
|---|---|
| 切换视口着色方式 | 鼠标悬停在 3D 视图上按 **Z**，选择模式 |
| 选择 / 隐藏某一层 | **大纲视图**（右上角）→ 点集合右侧的眼睛图标 |
| 查看物体的数值 | 选中物体，按 **N** 打开侧边栏 |
| 打开某个属性面板 | 右侧竖排标签图标（扳手 = 修改器） |
| 聚焦选中物体 | 选中后按**小键盘 .** |
| 切到相机视角 | 选中相机，按**小键盘 0** |

三种最常用的着色模式：

- **Solid（实体）**——灰模，最快，最适合看造型和拓扑
- **Material Preview（材质预览）**——按 **Z** 选它，不用打光就能看材质
- **Rendered（渲染预览）**——真实渲染效果，包含灯光

## 逐层解读

### `L1_场景基础` —— 物体与变换

*演示什么*：创建基本体、移动与缩放（`object.create`、`object.transform`）。

*怎么看*：选中 `L1_Cube`，按 **N**。侧边栏会显示它的位置、旋转、缩放。

*看什么*：这个立方体的缩放是 **0.6**——因为脚本在按 1.0 创建之后，又调用了
`object.transform` 把它缩小了。

### `L2_建模` —— 修改器

*演示什么*：`Bevel`（倒角）、`Subdivision`（细分）、`Boolean`（布尔）三种修改器，
以及破坏性的 `subdivide` 操作。

*怎么看*：选中 `L2_Bevel`，打开右侧属性栏的**扳手图标**，会看到一个实时的 `Bevel` 修改器。

*看什么*：

- 把 `L2_Subdiv` 的 **Subdivision** 修改器关掉再打开——立方体会在方块和圆滑之间切换
- `L2_BoolA` 上有一个 **Boolean** 修改器，用圆柱挖穿了一个孔。把作为刀具的
  `L2_BoolB` 隐藏起来看得更清楚
- `L2_Subd` 上没有修改器：`subdivide` 是直接改网格数据的

### `L3_材质` —— 材质系统

*演示什么*：材质系统与 Principled BSDF 参数。

*怎么看*：按 **Z** → **材质预览**。这个模式会用一张影棚 HDRI 照明，
不需要你自己打光就能判断材质效果。

*看什么*：

- `L3_Gold` 是金属（metallic 1.0，roughness 0.15）——它会镜像周围环境
- `L3_Red` 是哑光塑料（metallic 0.0，roughness 0.3）
- 选中任一物体，打开**材质**标签就能读到这些数值

### `L4_灯光相机` —— 三点布光与相机

*演示什么*：`lighting.create`、`camera.create`、`camera.look_at`，以及世界背景。

*怎么看*：

1. 按 **Z** → **渲染预览**，这是最终效果
2. 选中 `L4_Key`，打开**灯光**标签——功率是 700 W
3. 选中 `L4_Cam`，按**小键盘 0** 进入相机视角

*看什么*：三盏灯构成经典的主光 / 补光 / 轮廓光布局。
你可以把 `L4_Key` 改成 6000 W 试试——画面会完全过曝。这不是 bug，
面光源的瓦数就是这么直接。

### `L5_UV` —— UV 展开

*演示什么*：`uv.smart_project`。

*怎么看*：

1. 把任意一个区域切成 **UV 编辑器**（点区域左上角的编辑器类型按钮）
2. 选中 `L5_UVBox`，按 **Tab** 进入编辑模式，再按 **A** 全选

*看什么*：立方体的六个面会显示成整齐、互不重叠的 UV 岛，这是 Smart Project
把它切成六块的结果。

### `L6_动画` —— 关键帧

*演示什么*：`animation.keyframe_insert` 与场景帧范围。

*怎么看*：

1. 把时间轴拖回第 1 帧，按**空格**播放
2. `L6_Bounce` 会在 40 帧内弹起、自转、落回
3. 打开**图表编辑器**或**摄影表**可以看到关键帧菱形

*看什么*：`location` 和 `rotation_euler` 上**都**有关键帧——这就是它既弹跳又旋转的原因。

### `L7_角色骨骼` —— 角色与骨架

*演示什么*：角色模板系统与骨架创建。

*怎么看*：

1. 在大纲视图里把其他图层隐藏，免得角色被埋住
2. 选中 `L7_Rig`，把左上角的模式下拉切成**姿势模式**

*看什么*：角色由具名部件组成——`L7_Hero_Head`、`L7_Hero_Body`、`L7_Hero_Hair`、
`L7_Hero_Clothing_jacket`——它们全部由一个 `height` 值推导出来，
所以能严丝合缝地接在一起，而不是各飘各的。

### `L8_物理` —— 物理模拟

*演示什么*：布料与刚体模拟。

*怎么看*：

1. 把时间轴拖回第 1 帧
2. 按**空格**——布料平面会下落并垂下

*看什么*：选中 `L8_Cloth`，打开**物理**标签会看到 Cloth 面板；
`L8_Rigid` 上则是 Rigid Body 面板。

## 演示之外：渲染与导出

演示只搭建了几何、材质和灯光，没有做渲染。

- **渲染**：选中 `L4_Cam`，按 **F12**
- **导出**：任意物体都可以用 `blender_export_fbx` / `blender_export_gltf` /
  `blender_export_obj` 导出。游戏引擎的导出检查清单见
  [UNITY_QUEST_EXPORT.md](../UNITY_QUEST_EXPORT.md)

## 常见问题

**提示 "Could not reach Blender"** —— Blender 没开，或者插件没启用。
打开 Blender → `编辑` → `偏好设置` → `插件` → 启用 **Blender MCP**，
然后在 3D 视图侧边栏确认 MCP 面板。

**物体不见了，或者某一层看起来不对** —— 几乎可以肯定是重复运行却没加 `--clean`。
第二次运行会创建 `L1_Cube.001`，而部分操作仍然指向旧的 `L1_Cube`，
结果就是在改上一轮的物体。**请始终带上 `--clean`**。

**画面一片灰** —— 你在 Solid 模式下。按 **Z** 切换到材质预览或渲染预览。

**渲染出来全白** —— 灯光太强了。面光源单位是瓦，700 W 合理，6000 W 显然过头。

## 自动化测试

演示本身就是一个冒烟测试，但仓库里还有覆盖面大得多的测试套件：

```bash
python tests/run_live_test.py
```

它通过同一条 socket 跑 121 个断言、覆盖 47 个模块，最后打印通过/失败汇总。
和演示一样，**请在干净场景里跑**——上一轮残留的物体会造成误导性的失败。
